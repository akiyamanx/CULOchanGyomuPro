# No.025 写真付き下書きと保存済みレシートの再表示（2026-10-19）

## 使い方

- 「02 レシート」の保存済み一覧で「開く・修正」を押すと、写真・日付・店名・金額・種類を編集できる。同じ保存IDへ更新するため修正保存で重複しない。
- 「03 精算・PDF」の「下書きに付ける領収書」で「駐車場欄で選んだ分」を選び、「下書きを保存」。駐車場欄の表示月・日付で絞り込み、「PDFに載せる」にチェックした写真が対象。保存枚数の案内を確認する。
- 下書き一覧の「開く・修正」で精算書と「この下書きの領収書」が戻る。写真の説明（日付・会社名・機種・作業内容）も修正できる。
- 「この下書きの領収書PDFを見る」で説明付きA4横PDFを表示。下書き一覧の「領収書PDFを見る」からも直接表示できる。
- 読み込んだ下書きを修正して保存すると、新しい下書きを追加する。以前の下書きは残る。領収書を入れ替えるときは保存対象を「駐車場欄で選んだ分」へ変更する。

## 保存の境界

精算書・行明細・領収書写真・保存時の説明・4/6枚配置を独立したスナップショットとして保存する。通常の駐車場明細を後から変更・削除しても、保存済み下書きの写真や説明は変わらない。下書きの説明修正は精算書の金額や通常の駐車場明細を変更しない。写真調整結果・回転・PDF表示倍率も保持する。

新下書きは専用IndexedDB `CULOchanExpenseDrafts`。本体と一覧メタデータを同一トランザクションで保存/削除し、一覧表示で全写真を読み込まない。保存失敗を成功扱いしない。件数による自動削除は行わない。

旧 `travelExpenseDrafts` は削除・移行せず読み取り対応。旧下書きに写真は保存されていなかったので復元できない。必要な写真を選んで新しい下書きとして保存する。旧下書き読込時に現在の別の写真を自動で添付しない。

確認用ページの専用DBは `CULOchanExpenseDrafts_Preview_Expense_20261009`。同じ端末・ブラウザ・ページで利用する。別端末への同期はない。サイトデータ削除によって保存内容は失われる。
