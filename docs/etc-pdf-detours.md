# No.026 — ETC利用証明書と寄り道の確認

確認用ページでの追加機能。普段の公開トップページはこの変更の対象外。

## 使い方

「03 精算・PDF」→「ETC PDF・寄り道」を開く。月まとめPDFを追加し、日付を選ぶ。登録済みの訪問ルートから読み込むか、訪問順を手入力する。

「訪問順を確認・寄り道を追加」で、会社出発から会社帰着までの実際の訪問順を記録する。仕事は本部／別の仕事。元のマップの予定は変更しない。予定を読み直す場合、追加済みの寄り道を置き換える確認を出す。

「区間の距離・高速利用を確認」で距離を入力または計算し、本部／別の仕事／要確認を選ぶ。寄り道に接する区間は要確認。料金所名は任意の手がかり。Google Mapsの設定がない端末でも距離を手入力できる。

各証明書では、候補の移動区間を選び、提出先、提出額、訪問先、機種名、作業内容を確認して「確認して確定」。同順位の候補はその旨表示。元の証明書の印字は変更しない。共通区間の一部だけ提出するときは、提出額とメモを別記する。

「確定した分を精算書に反映」で同日の高速代・枚数・距離・行先を置き換える。既存のCSV・手入力の金額や距離がある場合は確認を出す。加算ではない。反映済みの日へのCSV追加は止める。駐車場代はこの操作では変更しない。

「本部提出用PDFを見る」で、この日の本部確定分だけをA4横・6枚または4枚配置で出力する。保留があれば除外を確認する。機種がない場合は「該当なし」と入力できる。精算書とは別の添付用PDF。

下書きを保存すると全保管ETC明細・証明書画像・日別の確認内容がスナップショットで保存される。読み込むと「下書きのETCを編集中」と表示され、通常の保管明細は上書きしない。再保存は新しい下書き。「保存済みのETCに戻る」で通常の保管明細へ戻る。

## 読み取りと対応範囲

- ETC利用照会の文字付きA4横PDF、5列×2段。1ファイル20MB・30ページまで。
- PDF.js 5.6.205（既存の依頼書読取と同じバージョン）、日本語CMapを指定。端末内処理。外部AI/APIキー不要。初回のライブラリ準備には通信が必要。
- 元の各枠を216dpi PNGに描画して保管する。元PDFファイル自体は保管せず、ファイル名・ページ・枠・取扱番号を残す。原本PDFは別途保管する。
- 日付・時刻・割引後の通行料金・取扱番号・事業者登録番号を読み取る。画像PDFや別配置、読めない枠があるファイルは全体の取込を停止し、部分成功として扱わない。
- 取扱番号＋事業者で重複を防ぐ。同番号で日付・時刻・料金・IC名が違う場合は停止する。
- CSVとの相互重複照合ではなく、同日の精算行を確認のうえ置き換える方式。

## 候補と再確認

候補は区間の高速設定、任意の出発・到着時刻、料金所名の一致、Mapsから得られる道路案内の名称を使って順位を付ける。一般的な地名からICの位置を推定する機能ではない。料金所名の別名辞書や実走行GPSは使わない。判別材料が少ない場合は複数の候補を残し、自動確定しない。

訪問順、住所、仕事、時刻、区間設定の変更後は、その日の確定を取り消す。安全側にその日全体を再確認する（前後区間だけに絞る最適化は行わない）。通常モードでは元のマップ予定の変更も検知し、予定の読み直しを求める。下書きモードは保存時点を保持し、元のマップとは独立。

距離計算失敗時は以前の距離を使わない。反映後の確認内容の変更・金額の直接編集があれば、精算書PDF出力時に再反映を求める。

## 保存先

ETC専用IndexedDB `CULOchanEtcEvidence`（v1）。確認用は `CULOchanEtcEvidence_Preview_Expense_20261009`。下書きは既存の独立した下書きDBに `etcEvidence` を追加。元の駐車場DBと旧下書きは保持。

## 確認記録

- Node自動試験60件成功（新規11件）。元の精算・駐車場・下書き・手入力の試験も含む。
- ユーザー提供PDFをローカルの同バージョンPDF.jsで読み取り、全6ページ56件。9月3日の3件・2,460円を確認。実ファイル・抽出画像・個別取扱番号はリポジトリへ保存していない。
- ブラウザ：6ページ56件の実PDF取込、日別3件表示、架空の会社→A→別仕事X→B→会社を作成。時刻で往路・帰路を候補提示。本部2件1,600円／別仕事1件、対象区間70kmのみを精算へ反映。A4横297×210mmのPDFを保存・描画して証明書と説明を確認。ETC付き下書き保存→再読込→復元、寄り道編集後の確定解除と古い精算PDF出力防止を確認。ブラウザ内の検証用仕分け・訪問順・距離は架空であり、実際の請求判断ではない。
- 320px幅のブラウザ内表示で本体幅305px／スクロール幅305px、ETC操作欄の横はみ出しなし。実機Androidでの印刷・共有は未検証。
- 実APIキーを使ったGoogle Mapsの距離・料金所照合は未実施。自動照合は候補提示で、正解保証や自動請求ではない。
