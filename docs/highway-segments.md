# 区間ごとの「途中から高速／途中まで高速」（IC指定）仕様

2026-11-04 作成（お試し版 v70 から）。

## 目的
走行距離の区間ごとに、下道と高速の切り替え地点（IC）を指定できるようにする。
これまでは区間ごとに「下道」か「高速」の2択だった。

## 区間の種類
| 種類 | 保存値 | 計算 |
|---|---|---|
| 🚗 下道 | `'general'`（従来どおり文字列） | 出発→到着を一般道（avoidHighways） |
| 🛣️ 高速 | `'highway'`（従来どおり文字列） | 出発→到着を高速可 |
| ↗️ 途中から高速 | `{type:'hwFrom', ic:{name,lat,lng}}` | 出発→IC を一般道 ＋ IC→到着 を高速可 |
| ↘️ 途中まで高速 | `{type:'hwUntil', ic:{name,lat,lng}}` | 出発→IC を高速可 ＋ IC→到着 を一般道 |

- 古い保存データ（文字列）はそのまま読める。`HighwaySegments.normalize()` が読み替える。
- 知らない値は「下道」とする（従来の既定値と同じ）。
- ICが未指定の「途中から／途中まで」は計算前にICを選ぶよう求める。それでも残った場合は「高速」として計算する。

## 距離の合成（精算の規則を変えないため）
- 区間の距離 = round（下道部分のm ＋ 高速部分のm ÷ 1000）。整数km。
- 下道km = round（下道部分のm ÷ 1000）。高速km = 区間km − 下道km。
- 合計km は区間kmの合計。精算（100kmまで無料、101〜200kmは30円/km、201km以上は38円/km）は従来どおり合計kmだけを使う。
- 内訳表示は 0.1km 単位：「下道 12.3km ＋ 高速 45.6km（浮島ICから乗車）」。
- Directions の呼び出しは「途中から／途中まで」の区間だけ2回になる。

## ICの選び方
1. ⭐ よく使うIC：使った回数・最終利用日の順。設定（settings.icFavorites）に保存するので、全体バックアップに含まれる。
2. 📍 この区間の近く：出発と到着を結ぶ線から近い順（線から15km以内、最大8件）。
3. 🗺️ 地図で選ぶ：地図をタップした地点から一番近いIC。地図がない環境（お試し版など）ではボタンを無効にする。
4. 🔍 名前で探す：同梱の一覧から名前で絞り込み。

## IC一覧
- `map/ic-kanto.js`：Wikidata（CC0）の「インターチェンジ」（Q2376564）のうち関東周辺（経度138.9〜140.95、緯度34.85〜36.95）。
- 名前・緯度・経度・路線。ジャンクションは除外。位置は目安。
- 外部APIは呼ばない（追加の費用なし）。

## やらないこと
- 料金（通行料）の自動計算。
- 一覧にないICの手入力登録（必要なら次の段階）。
