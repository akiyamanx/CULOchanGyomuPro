# 仕事の流れに沿う画面整理 — 2026-10-14

## 目的と設計
訪問準備 → 現場での記録 → 帰着後の精算を、3つの常設入口で辿れるようにする。
最初に訪問・ルートを開き、現在の段階を文字と選択表示で示す。順番は案内であり、レシートや精算へ直接移動できる。

- 訪問・ルート：対象月、訪問先追加、ファイル取込、訪問先／ルート／進捗を先に表示。地図はPCで隣、狭い画面で下。キー未設定でも一覧・編集は利用可能にする。
- レシート：画像選択 → 読み取り・確認 → 保存を一画面で順に案内。駐車場記録と精算への入口を設置。
- 精算・PDF：ルート・ETC・駐車場の取込をまとめ、基本情報、日別明細、合計・保存・PDFへ進む。船賃・航空賃等は折りたたむが入力済みなら開く。
- 主操作は青、補助操作は白い枠付き、保存済み・完了は緑、注意は黄、削除は赤い文字。複数の鮮やかなグラデーションは使わない。
- Noto Sans JPを先頭にしたフォント指定。本文16px、主要タッチ領域44px以上、明るい入力面と濃い文字、キーボードのフォーカス表示、拡大を許可する。
- 画面幅が狭い場合は1列＋下部ナビ、広い場合は左ナビ＋作業領域。地図の巨大な空白、曖昧なアイコン単体、精算入口の重複、地図スワイプで別アプリを開く挙動を避ける。
