Googleカレンダーの予定を見ながら訪問日時を決める

初回だけ、Google側でこのアプリ用の接続設定を作ります。設定後は訪問先の編集画面で「Googleカレンダーに接続」を押すと、選んだ日の予定の時間・内容・場所が表示されます。

これはGoogleの予定を読むための設定です。地図のAPIキーとは別です。Googleのパスワード・クライアントシークレット・アクセストークンをアプリやチャットに入力する必要はありません。

1. Google側で準備する

  1. Google Cloud Consoleを開き、使うGoogleアカウントでログイン。自分で管理しているプロジェクトを選びます（既存の地図用プロジェクトでも構いません）。
  2. 「APIとサービス」→「ライブラリ」で Google Calendar API を検索し、有効にします。
  3. 「Google Auth Platform」でアプリ情報を設定。名前は「CULOchan訪問予定」など自分で分かる名前にします。連絡先メールはご自身のものを入力します。
  4. 個人のGoogleアカウントなら「対象／Audience」は外部／External。まず「テスト」状態で、テストユーザーに接続するご自身のGoogleアカウントを追加します。組織アカウントでは管理者の制限に従ってください。
  5. 「データアクセス／Data Access」で、予定を読む https://www.googleapis.com/auth/calendar.events.readonly と、カレンダー一覧を読む https://www.googleapis.com/auth/calendar.calendarlist.readonly を追加します。
  6. 「クライアント／Clients」→「クライアントを作成」。アプリケーションの種類はウェブ アプリケーション。
  7. 「承認済みのJavaScript生成元」に https://akiyamanx.github.io を追加します。末尾のスラッシュ、/CULOchanGyomuPro/ や /preview/… は付けません。この方式ではリダイレクトURIの追加は不要です。
  8. 作成されたクライアントID（末尾が .apps.googleusercontent.com）だけをコピーします。シークレットは使いません。

2. アプリで接続する

  1. 訪問先のピン／一覧から「日時・備考を編集」を開きます。
  2. 予定欄の「接続設定を開く」（接続中は「連携設定」）を押します。設定の「Googleカレンダー」→「初回の連携設定」にクライアントIDを貼り、「連携用IDを保存」。画面上部の「設定」からも同じ項目を開けます。
  3. 「Googleカレンダーに接続」を押し、Google画面でアカウントを選びます。予定とカレンダー一覧の閲覧を両方許可すると表示できます。
  4. 「表示するカレンダー」で、仕事用・個人用など確認したいものを選択。
  5. 「入力中の画面に戻る」で訪問先の編集へ戻ります。訪問日を入力するか、前日／翌日のボタンや月カレンダーで日付を選びます。既存予定を見ながら、時刻と備考を入力して保存します。

Googleの予定を変更したら「更新」を押します。ページの再読み込みや接続期限切れの後は、設定の「Googleカレンダー」から接続し直してください。Googleへの新規予定の登録は、従来どおり保存後の「Googleカレンダーに追加」から確定します。

表示できないとき

  • origin_mismatch：JavaScript生成元を確認。変更が反映されるまで時間がかかる場合があります。
  • access_denied／アクセスをブロック：テストユーザーの登録、Google側の閲覧許可、組織の管理者設定を確認します。
  • Googleの接続画面が開かない：アプリ内ブラウザではなくChromeやEdgeでアプリを開き、ポップアップを許可します。
  • 403／読み込み失敗：同じプロジェクトでCalendar APIが有効か、両方の閲覧権限を許可したか確認。失敗中は「予定なし」とは判断しません。
  • 予定の内容が非公開：共有されたカレンダーの権限によっては時間だけが見えます。確認できないカレンダーはGoogle側でも確認してください。

データの扱い

Googleの予定は閲覧だけに使います。この機能からGoogleの予定を作成・変更・削除しません。Googleから読み込んだ内容と接続トークンは、このページを開いている間だけメモリに保持し、GitHub・精算書・下書き・ブラウザの保存領域には保存しません。接続用クライアントIDだけを端末のブラウザに保存します。予定の通信先はGoogle Calendar APIです。

設定の「Googleカレンダー」内の「接続解除」で確認すると、この画面のデータを消し、Googleへの許可の取り消しも要求します。通信などで取り消せなかった場合はGoogleアカウントの接続管理でも確認できます。

アプリ独自に入力した訪問予定は従来どおりこのブラウザに保存されます。Google予定と同じ訪問を両方に登録した場合は、出所が分かるよう両方を表示します。表示は日本時間。開始時刻の重なりを案内しますが、作業の終了時刻や移動時間から空き時間を自動保証する機能ではありません。

設定の基準：Google公式・JavaScriptクイックスタート ／ Google公式・Token model
