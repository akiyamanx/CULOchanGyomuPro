# No.024 レシートの手入力・読取失敗からの復帰（2026-10-19）

「02 レシート」の読取結果が表示専用だったため、AIが失敗すると「読取失敗・0円」のまま登録を進められなかった。写真を保持し、日付・店名/駐車場名・金額・種類を直接修正できるようにした。

## 操作

1. レシート画像を選ぶ。1枚なら「この画像を1枚として手入力」、複数写っている場合は検出して「AIを使わず手入力」を選べる。
2. AI読取の成功/失敗にかかわらず、写真の下の入力欄で確認・修正する。住所・入庫時刻は任意。
3. 一般レシートは「内容と写真を保存」。駐車場の領収書は種類を「駐車場」にして「駐車場明細へ取り込む」。取り込み時点で写真と金額を駐車場用の保存領域へ保存する。
4. 駐車場明細で訪問先を選び、機種・目的を確認して、既存のA4横・6枚PDFへ進む。

未読の金額は空欄で表示する。日付・店名・金額・種類が未確定の明細は保存/駐車場への転記を止める。0円は明示的に入力した場合のみ受け付ける。
手修正済みの内容はAI再読取で上書きしない。同一写真の再保存は更新し、同日・同店・同額でも写真が別なら別明細として保持する。すでに駐車場へ取り込んだ写真の再取込は重複追加せず、駐車場明細側での修正を案内する。

## 保存と制限

入力中は画面内に保持。「保存」または「駐車場明細へ取り込む」が完了する前に再読み込みすると入力中の内容は失われる。写真選択/クリア/再検出時には入力を閉じる確認を表示する。ブラウザ容量不足時は成功扱いせず写真と入力を残す。
一般レシートの保存先は従来のlocalStorage、駐車場明細はIndexedDB。確認用ページは両方とも普段の画面と別の領域を使う。
APIキーの正否や今回の実際の読取失敗理由は未確認。API応答本文や読取内容をコンソールへ出さず、キーなどを含む可能性のある応答を画面に転記しない。
