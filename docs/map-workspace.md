# 大きな地図で電話・訪問予定を組む — 2026-10-19

## 操作
1. 「01 訪問・ルート」で「地図を大きくして予定を組む」を押す。
2. 地図を広げたまま、必要なら「訪問先・ルート」で一覧を表示。広い画面では右側、狭い画面では地図の下に表示する。
3. ピンの「日時・備考を編集」を押す。電話番号ごとの発信リンク、Googleカレンダーを開くリンク、訪問日・時刻・アポ状態・ルート・備考をまとめて表示する。
4. アプリ内の月カレンダーで日を選び、保存済みの訪問予定を確認しながら入力。「予定・備考を保存」で保存する。
5. アプリ保存後、必要ならGoogleカレンダーの追加画面を開いて利用者が登録する。Googleカレンダーへ自動保存・自動同期はしない。

## 表示と境界
- 通常画面の地図も高さを拡大。スマホでは地図を一覧より上に配置。
- 拡大時は既存の地図をそのまま使い、中央位置を保持。表示切替による住所再検索や距離再計算はしない。
- アプリの訪問予定は、この端末・この画面の全月ワークスペースから表示する。Google接続後は、Google側の時間・内容・場所も別枠で表示する。初回設定は `google-calendar-setup.html`、実装境界は `google-calendar-integration.md` を参照。
- 同じ開始時刻の別訪問は案内する。作業時間・移動時間を知らないため、予定の重なりや空き時間を自動確定しない。
- 日付だけで時刻を勝手に補わない。日付と時刻の片方だけでは保存しない。
- 電話リンクは端末の電話アプリへ渡す。実際の発信や、Googleカレンダーへの追加確定は利用者が行う。
- 未保存の編集を閉じるときに破棄確認。保存容量不足で保存できない場合は入力を残し、成功表示を出さない。
- 検証用ページの保存先分離を維持。本番ルートへの統合は行っていない。
